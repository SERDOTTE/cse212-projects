Replace code explication

The objective is to find and replace all occurrences of a specific value (`oldValue`) with a new value (`newValue`) within a Linked List.

1. Initialization of the Traversal Pointer
- An auxiliary pointer, `curr`, is initialized to point to the first node of the list (`_head`).
- If the list is empty (`_head == null`), `curr` starts as `null`, and the search does not even begin.

2. Traversing the Entire List (while loop)
- The `while` loop continues as long as `curr` points to a valid node.
- The traversal proceeds from the beginning (`_head`) to the end (`_tail`) until `curr` becomes `null` (indicating the end of the list).

3. Value Verification and Replacement
- At each visited node, the code compares `curr.Data` with `oldValue`.
- If the values ​​match, the `Data` field of that node is updated directly with the new value (`newValue`).

4. Advancing to the Next Node
- The `curr` reference is updated to point to the next node in the chain (`curr.Next`).
- No `return` or `break` statements are used within the `if` block. 
- This ensures that the algorithm continues traversing the entire list until the end, allowing all occurrences of `oldValue` to be found and replaced with `newValue`.
